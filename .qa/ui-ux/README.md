# UI/UX Figma audit artifacts

Các lần chạy `/ui-ux-figma` có thể lưu screenshot, trace, measurements và report tại đây.

Chạy command bằng cách cung cấp:

```text
/ui-ux-figma FIGMA_URL=<figma-frame-url> SITE_URL=<website-url>
```

Mỗi run nên có viewport, route, commit và trạng thái authentication rõ ràng.
